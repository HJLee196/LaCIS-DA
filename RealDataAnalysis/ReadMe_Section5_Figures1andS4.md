# ReadMe_Section 5 – Figures 1 and S4

- This document describes how to use the following R scripts to generate Figures 1 and S4:
  - `Figure_1_AB/RealData_qvalue_scatter.R`
  - `Figure_1_CDE/conditional_microglia_multidecomp_LR.R`
  - `Figure_1_CDE/volcano.R`
  - `Figure_S4/Enrich_realdata.R`

- `UtilityFunctions.R` is required by `RealData_qvalue_scatter.R`, `volcano.R`, and `Enrich_realdata.R`. Ensure that it is accessible from the current working directory.

### Figure 1 (Panels A and B)

- `Figure_1_AB/RealData_qvalue_scatter.R` generates `BH_vs_LaCIS_panels.pdf`, which corresponds to Panels A and B in Figure 1.

- The following data files are required. They are generated by  
  `46_47_mother_code_multidecomp_realdata-AllPart12.R` and  
  `48_mother_code_BH_realdata.R`, respectively:
  - `HuVascAD_cellastrocyte_methodmultidecomp_testUseMAST_downNULL_gene23537_PC43_10llam1_seed2017_maxIterImp100.rda`
  - `HuVascAD_cellastrocyte_testUseBH_downNULL_gene23537_PC43_10llam1_seed17_maxIterImp100.rda`

- Place the two data files in the current working directory of your R session and run `RealData_qvalue_scatter.R`. The script will save `BH_vs_LaCIS_panels.pdf` in the same directory.

### Figure 1 (Panels C, D, and E)

- `Figure_1_CDE/volcano.R` generates `conditional_microglia.pdf`, which corresponds to Panels C, D, and E in Figure 1.

- You must first run `Figure_1_CDE/conditional_microglia_multidecomp_LR.R` to generate `HuVascAD_cellmicroglia_testUseBH_downNULL_gene23537_PC11_10llam1_seed17_maxIterImp100_conditional_multidecomp_LR.rda`.

- `conditional_microglia_multidecomp_LR.R` requires the following data files, which are generated by  
  `46_47_mother_code_multidecomp_realdata-AllPart12.R` and  
  `48_mother_code_BH_realdata.R`, respectively:
  - `HuVascAD_cellmicroglia_methodmultidecomp_testUseLR_downNULL_gene23537_PC11_10llam1_seed2017_maxIterImp100.rda`
  - `HuVascAD_cellmicroglia_testUseBH_downNULL_gene23537_PC11_10llam1_seed17_maxIterImp100.rda`

- `conditional_microglia_multidecomp_LR.R` also requires `HuVascAD_microglia.rds` in the current working directory.

- Place all three required input files in the current working directory of your R session and run `conditional_microglia_multidecomp_LR.R`. The script will save `HuVascAD_cellmicroglia_testUseBH_downNULL_gene23537_PC11_10llam1_seed17_maxIterImp100_conditional_multidecomp_LR.rda` in the same directory.

- `volcano.R` requires the following data files:
  - `HuVascAD_cellmicroglia_testUseBH_downNULL_gene23537_PC11_10llam1_seed17_maxIterImp100_conditional_multidecomp_LR.rda`
  - `HuVascAD_cellmicroglia_testUseBH_downNULL_gene23537_PC11_10llam1_seed17_maxIterImp100.rda`

- Place the two data files in the current working directory of your R session and run `volcano.R`.  
  The script will save `conditional_microglia.pdf` in the same directory.

### Figure S4

- `Figure_S4/Enrich_realdata.R` generates `ko_enrichment_PC43_GO_BP_ORA.jpg`, which corresponds to Figure S4.

- The following data file is required. It is generated by  
  `46_47_mother_code_multidecomp_realdata-AllPart12.R`:
  - `HuVascAD_cellastrocyte_methodmultidecomp_testUseMAST_downNULL_gene23537_PC43_10llam1_seed2017_maxIterImp100.rda`

- Place the data file in the current working directory of your R session and run `Enrich_realdata.R`. The script will save `ko_enrichment_PC43_GO_BP_ORA.jpg` in the same directory.
